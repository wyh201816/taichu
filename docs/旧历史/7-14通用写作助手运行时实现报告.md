# 通用写作助手 Runtime 实现报告

> 更新日期：2026-07-14
> 状态：废弃的旧实现快照，不替代当前代码、已讨论功能或学习资料中的实现说明

## 一、实现结论

通用写作助手后端 Runtime 主链已经完成。系统现在能够由高层编排 Agent 理解任意规模的写作相关请求，从已注册的十六个真实 Tool 和十二个真实专业子 Agent 中选择最小充分能力，生成动态 DAG，按依赖异步执行，并经过结果校验、有限重规划或人工中断后收敛为最终回答。

本次没有把通用 Runtime 混入知识沉淀 Workflow。两者拥有独立的业务运行模型、检查点目录、事件中心、状态流转和后续评测入口；只共享 Tool、专业子 Agent、LLM 网关、统一召回及脱敏技术调用轨迹。

本次对应四阶段开发任务中的第一项。智能体工作台页面、通用 Runtime 节点监控页面和专属效果评测将在后续三个独立提交中实现。

## 二、核心实现

### 高层编排 Agent

新增高层编排 Agent，负责：

- 读取真实 Tool 与专业子 Agent Manifest，按当前请求生成计划。
- 判断是否可以直接回答、需要澄清、调用一个能力或组织多节点执行图。
- 校验计划只引用注册能力、依赖无环、外部研究符合用户许可。
- 在执行结束后对照目标、作者约束和真实节点结果进行校验。
- 仅在存在可修复缺口且未超过上限时触发重规划。

高层编排 Agent 不是专业子 Agent，不承担设定、人物、写作或审校的单点职责，也不会临时创建任务专用能力。

### 顶层 LangGraph 与动态 DAG

顶层 LangGraph 承载初始化、规划、执行、校验和重规划循环。单次计划中的能力节点构成动态 DAG：

- 节点只能是已注册 Tool 或专业子 Agent。
- 无依赖节点按任务并发上限异步执行。
- 失败节点会按计划声明决定是否阻断下游，阻断节点明确标记为跳过。
- 上游结构化输出可通过显式字段路径绑定到下游输入。
- 专业子 Agent 的有类型中间产物引用会沿依赖边自动传递。
- 成功节点保存后不会在普通恢复中重复执行。

自动化验收使用真实 `retrieve_knowledge`、`canon_evidence`、`preview_manuscript_patch` 和 `apply_manuscript_patch`，没有为 Runtime 新增假 Tool、假 Agent 或独立测试型执行器。

### 人工中断与权限

Runtime 支持两类人工中断：

- 信息澄清：只有缺口会实质改变结果时暂停，作者补充后重新规划。
- 写入授权：任何持久化 Tool 执行前都保存绑定后的确定输入、规范化输入哈希、作用范围和二次确认要求；作者批准后才签发短期授权。

外部研究仍默认关闭。只有请求显式携带外部访问许可时，Runtime 才为本任务签发限定到搜索与来源读取 Tool 的短期许可。

### 检查点、恢复与取消

通用 Runtime 使用独立 JSON 仓储，在每次生命周期变化和节点批次变化后原子保存检查点。检查点位于：

`project_assets/derived/general_agent_runs/`

服务重启时，仍在规划、执行或校验中的任务会封存为可恢复失败状态，运行中的节点复位到安全位置。恢复时复用已成功节点和中间产物；进程内授权不会跨重启直接复用，而是依据检查点中保存的作者决定、原输入和原作用范围重新签发。真实写 Tool 继续使用正文哈希、结构版本、知识更新时间和幂等键防止静默覆盖。

后台任务可以取消；完成和取消状态不可恢复，失败与超时可以从检查点继续或重新规划。

## 三、HTTP API

通用 Runtime 使用独立路由前缀：

`/api/agent-workbench/general-assistant`

当前提供：

- 同步执行到结束或人工中断。
- 后台创建并立即返回初始检查点。
- 分页查询运行列表与单次运行详情。
- 回答澄清、批准或拒绝写入并恢复。
- 取消和删除运行。
- 订阅独立 NDJSON 事件流。

接口精确字段以 `src/taichu/api/schemas/general_agent.py` 为准，页面不得自行复制另一份状态契约。

- 高层编排 Agent 使用独立模型角色生成计划和最终校验。

- 信息澄清后重新规划。
- 校验失败后的单次有限重规划。

## 六、已知边界与后续工作

- 工作台尚未提供通用写作助手输入、运行进度、澄清和授权交互。
- 任务监控页尚未读取通用 Runtime 的独立检查点和事件流。
- 尚未建立通用 Runtime 专属评测集、指标和评测结果存储。
- 运行时记忆与上下文压缩尚未实现；当前检查点保存结构化计划和关键结果，但不承担长期记忆职责。
- 强制断电恰好发生在外部写入成功、节点完成检查点尚未写入的极小窗口时，恢复仍依赖真实写 Tool 的哈希、版本、身份冲突和幂等保护识别不确定结果；后续应增加故障注入基准。
- 最大稳定节点数、不同并发度下的成功率和真实模型计划稳定性需要在通用 Agent 专属评测阶段验证。
