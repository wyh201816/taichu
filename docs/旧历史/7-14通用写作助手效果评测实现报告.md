# 通用写作助手效果评测实现报告

> 更新日期：2026-07-14

## 一、实现结论

通用写作助手已经拥有独立效果评测入口、评测模型、结果仓储、HTTP API 和内置核心评测集。评测对象是通用 Agent 的同题历史运行，成功标准围绕开放式任务是否完成、能力路径是否最小充分、权限是否越界、执行是否健康以及答案是否覆盖参考要点，不复用知识沉淀 Workflow 的知识卡匹配和字段评分模型。

## 二、评测口径

每次评估输出五个维度及逐项检查：

- 任务完成度：问题、正文范围和终态是否符合样例。
- 能力选择与路径：必要能力、可替代能力组、禁止能力和节点规模是否符合最小充分原则。
- 权限与安全边界：联网许可、节点内部调用、作者写入授权和人工中断位置是否正确。
- 执行健康度：失败节点、悬空节点、重规划次数和系统错误。
- 答案覆盖度：参考要点、禁用内容和事实来源引用。

总体分数按固定权重聚合；关键安全项失败时不能仅靠其他高分通过。创作、规划和改写样例会明确标记“确定性检查通过后仍需语义或人工复核”，避免把词法要点覆盖误称为完整文学质量评分。

## 三、内置评测集与参考答案

评测基准位于 `tests/fixtures/evaluations/general_writing_assistant_core/manifest.json`，显式标记 `lifecycle=confirmed`，包含 8 道题及参考答案：

1. 小金修炼七天后的事实问答。
2. 冲突场景的直接写作建议。
3. 秦浩轩鼓励小金同时担心风险的人物分析。
4. 小金妖气风险的三步剧情规划。
5. 隐藏小金妖气的短场景草稿。
6. 保持人物克制前提下增强选区紧张感。
7. 鼓励与担心是否构成人设矛盾的一致性审查。
8. 修改第 82 章标题时必须进入作者写入授权。

这些题覆盖直接回答、单能力、多能力动态 DAG、事实取证、创作、审校和人工中断。评测服务按文件内容计算校验和并冻结到每条结果，后续修改基准不会静默改变历史评估含义。

## 四、产品交付

- 任务监控的通用写作助手区域新增“效果评测”页签和总入口卡片。
- 页面可选择评测集、样例和目标完全一致的历史任务；没有同题任务时可复制问题到工作台运行。
- 页面展示问题、参考答案、预期范围、节点规模、必要能力和人工复核说明。
- 评估结果展示总体分数、五个维度、逐项通过/失败原因、关键失败项、实际答案和冻结参考答案。
- 支持历史评估列表、详情查看和删除；删除评估不会删除原任务。
