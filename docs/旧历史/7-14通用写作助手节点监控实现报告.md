# 通用写作助手节点监控实现报告

> 更新日期：2026-07-14

## 一、实现结论

通用写作助手已经拥有独立的任务监控入口，可以按真实运行查看动态计划、依赖关系、节点状态、历史计划修订、人工授权、生命周期与分层调用明细。该监控直接消费通用 Agent Runtime 的业务检查点和能力层脱敏调用记录，不复用知识沉淀 Workflow 的业务日志、固定节点图、状态机或评测模型。

## 二、后端交付

- 为能力调用记录仓储增加按 `run_id` 的只读查询契约，保留原有追加写入契约，避免调用方因监控读取能力而承担额外依赖。
- JSONL 读取按运行过滤、按开始时间排序并设置返回上限；单条损坏的派生记录不会阻断整个监控页面。
- 通用 Agent API 增加单次运行的脱敏调用记录读取接口，并先校验业务运行是否存在。
- 接口只返回既有脱敏技术字段，不返回完整输入、Prompt、模型原文、外部页面全文或鉴权信息。

## 三、前端交付

- 任务监控入口增加“通用写作助手节点监控”，并独立统计通用 Agent 任务与活动状态。
- 新增通用 Agent 监控页面，支持全部、运行中、等待作者、已完成和异常筛选。
- 根据单次运行的真实节点与依赖动态布局 DAG，不把某条固定写作流程写死到页面。
- 支持切换当前及历史计划修订，查看重规划产生的旧节点图。
- 节点详情展示能力、节点类型、目标、依赖、状态、耗时、来源、授权和错误。
- Tool 与专业子 Agent 内部 Tool/LLM 调用折叠在所属节点；高层规划与结果校验调用单独展示。
- 生命周期区域展示 Runtime 独立状态变化及原因。
